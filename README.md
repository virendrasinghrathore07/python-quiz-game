# 🎯 Python Quiz Game

A simple **Command-Line Quiz Game** built using Python.

This project asks the user basic computer-related questions and calculates the final score and percentage based on the correct answers.

## 🚀 Features

* Simple command-line interface
* Asks multiple computer-related questions
* Case-insensitive answers
* Calculates total score
* Calculates percentage
* Gives instant feedback for each answer
* Beginner-friendly Python project

## 🧠 Questions Covered

The quiz currently contains questions about:

* CPU — Central Processing Unit
* GPU — Graphics Processing Unit
* RAM — Random Access Memory
* PSU — Power Supply Unit

## 🛠️ Technologies Used

* Python 3
* `input()`
* `if-else`

* `.lower()`

## 📊 Scoring

The game contains **4 questions**.

* Each correct answer = 1 point
* Maximum score = 4
* Percentage = `(score / 4) × 100`
